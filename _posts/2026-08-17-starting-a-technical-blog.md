## 为什么建立这个博客

我希望把零散的技术学习过程整理成可以长期检索的记录，而不是只停留在临时笔记或聊天记录中。

## 这个博客会记录什么

目前计划记录以下内容：

- Git 和 GitHub 的学习过程
- 编程项目的实现过程
- 问题排查和解决方案
- AI 工具的使用经验
- 对技术概念的理解和总结

## 第一阶段目标

第一阶段先完成博客的基础结构，熟悉以下流程：

1. 使用 Markdown 写文章
2. 使用 Git 记录修改
3. 将内容推送到 GitHub
4. 使用 GitHub Pages 发布网站
5. 持续维护和整理文章

这篇文章是这个博客的起点。
